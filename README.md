# 🪐 Zo7al Bot v2

بوت ألعاب ديسكورد باسم **Zo7al**، يدعم العربية والإنجليزية و**24 لعبة**. كل الأوامر تعمل بالسلاش `/` وبالبادئة `-` مع الاختصارات العربية والإنجليزية. صور المشاهير والأعلام والشعارات مرفقة بالمستودع.

## التشغيل

1. ثبّت **Node.js 22.12 أو أحدث**.
2. نزّل المستودع، أو نفذ:

   ```bash
   git clone https://github.com/iiZo7al/zo7al-bot.git
   cd zo7al-bot
   npm ci
   ```

3. انسخ `.env.example` إلى `.env`:

   ```bat
   copy .env.example .env
   ```

   في Linux/macOS استخدم `cp .env.example .env`.

4. ضع توكن البوت في `DISCORD_TOKEN` داخل `.env`. لا ترفع هذا الملف إلى GitHub. المتغير القديم `token` ما زال مدعومًا.
5. من [Discord Developer Portal](https://discord.com/developers/applications) → تطبيقك → **Bot**، فعّل **MESSAGE CONTENT INTENT**. يحتاجه البوت لأوامر البادئة وإجابات الألعاب. لا يحتاج Presence Intent أو Server Members Intent.
6. ادعُ البوت مع نطاقي `bot` و`applications.commands`، وأعطه صلاحيات:
   - View Channel
   - Send Messages
   - Send Messages in Threads إذا ستلعب داخل الثريدات
   - Embed Links
   - Attach Files
   - Read Message History
7. شغله:

   ```bash
   npm start
   ```

على Windows: `_build.bat` يثبت المكتبات ويفحص الملفات، و`_run.bat` يشغل البوت. الأوامر لا تنزّل إصدار Node مختلفًا عند كل تشغيل.

يسجل البوت أوامر السلاش تلقائيًا عند التشغيل. لتسجيلها فورًا في سيرفر تجربة ضع `GUILD_ID` في `.env`. إذا حذفت `GUILD_ID`، يسجلها عالميًا وقد تحتاج Discord إلى بعض الوقت لعرضها.

يمكن تسجيل الأوامر منفصلًا عبر `npm run deploy` بعد وضع `CLIENT_ID` و`DISCORD_TOKEN`، ثم تعطيل التسجيل عند الإقلاع باستخدام `REGISTER_COMMANDS=false`.

## جميع الألعاب والاختصارات

كل الأسماء أدناه متاحة مع `-` أو `/`. لا يسمح Discord بأحرف إنجليزية كبيرة في اسم السلاش: `-cutTweet` يعمل، والسلاش هو `/cuttweet`.

| اللعبة | الأمر والاختصارات |
|---|---|
| من هو هذا المشهور؟ | `img`, `i`, `صور`, `خمن`, `مشاهير` |
| خمن اسم الدولة | `flags`, `f`, `اعلام` |
| خمن الشعار التجاري | `brands`, `علامات`, `شعارات` |
| ما هي عاصمة الدولة؟ | `capitals`, `c`, `عواصم` |
| اشبك الأحرف | `combine`, `اشبك`, `شبك` |
| كت تويت على السريع | `cuttweet`, `cutTweet`, `cut`, `كت` |
| أضف النقاط للحروف | `dots`, `نقاط` |
| تذكر الإيموجي الصحيح | `emojis`, `e`, `ايموجي` |
| عد حروف الكلمة | `letters`, `l`, `letter`, `حروف` |
| حل المسألة | `math`, `m`, `رياضيات` |
| اعرف الحرف المفقود | `missing`, `حرف` |
| اكتب الرقم | `numbers`, `num`, `ارقام` |
| خمن مضاد الكلمة | `opposite`, `o`, `مضاد` |
| خمن جمع الكلمة | `plural`, `جمع` |
| تحدي أصحابك وعاقبهم | `punish`, `عقاب` |
| اعكس الكلمة | `reverse`, `r`, `عكس` |
| أسرع كتابة | `rewrite`, `type`, `اسرع` |
| خمن مفرد الكلمة | `single`, `مفرد` |
| فكك الجملة | `spell`, `fkk`, `فكك` |
| ترجمة الكلمات | `translate`, `tran`, `ترجمة` |
| المارد السحري | `aki`, `المارد` |
| حجرة ورقة مقص | `rps`, `حجرة`, `مقص` |
| إكس أو | `ttt`, `xo`, `ox` |
| عجلة الأسماء | `wheel`, `wh`, `عجلة` |

### أمثلة

```text
/flags
-صور
-m
-combine
-rps @Friend
-ttt @Friend
-punish @Friend
-wheel Ali, Sara, Khaled
```

في السلاش، اختر الصديق في حقل `user` لأوامر `/rps` و`/ttt` و`/punish`. لا يبدأ التحدي حتى يقبله الصديق، ويُرفض اختيار نفسك أو بوت أو مستخدم خارج السيرفر.

`/wheel` بدون أسماء يفتح التسجيل بالأزرار. صاحب الأمر يبدأ السحب بعد انضمام لاعبين على الأقل، ويغلق التسجيل تلقائيًا بعد 40 ثانية. يمكن تمرير `names` مع أسماء مفصولة بفاصلة إنجليزية أو عربية. من 2 إلى 20 اسمًا.

`/emojis` يعرض الإيموجي 3 ثوانٍ ثم يخفيه ويعرض 4 اختيارات. أول اختيار ينهي الجولة.

`/punish` تحدي ردة فعل: انتظر الضوء الأخضر. الضغط مبكرًا خسارة. الخاسر يحصل على تحدٍّ مرح في الشات، مثل كتابة اسمه بالعكس؛ لا تُطبّق عقوبات إدارية.

`/reverse` يعكس حروف الكلمة المعروضة. `/missing` يقبل الحرف الناقص أو الكلمة كاملة. `/letters` لا يحسب المسافات أو التشكيل. الأرقام العربية والإنجليزية مقبولة، ولا تفرق الإجابات بين الأحرف الإنجليزية الكبيرة والصغيرة.

لعبة `/dots` تستخدم كلمات عربية حتى في السيرفرات الإنجليزية لأنها تعتمد على نقاط الحروف العربية.

### المارد

`/aki` يحاول الاتصال بـ Akinator بالعربية أو الإنجليزية، مع أزرار نعم / لا / لا أعرف / غالبًا / غالبًا لا، ورجوع وتأكيد أو رفض التخمين. إذا تعذرت الخدمة، يبدأ جولة من قاعدة زحل المحلية التي تضم **40 شخصية** حقيقية وكرتونية ويظهر هذا بوضوح في الجولة. لا يحتاج مفتاح API. يمكن إجباره على العمل محليًا باستخدام `AKINATOR_MODE=local`.

الاتصال بخدمة Akinator يعتمد على توفر موقعها وقد يتوقف بسبب تغييرات الموقع أو حجب الاستضافة. قاعدة زحل المحلية تعمل بدون اتصال بالخدمة. لا تُحتسب نقاط للمارد أو كت تويت أو عجلة الأسماء.

## النقاط والإدارة

| الأمر | الوظيفة |
|---|---|
| `/help` أو `-مساعدة` | قائمة كاملة داخل نفس الروم، مع كل الاختصارات |
| `/ping` | استجابة البوت |
| `/points` | نقاطك، أو نقاط مستخدم تحدده في `user` |
| `/profile` | ملف اللاعب وصورته ونقاطه |
| `/top` | أعلى 10 لاعبين عالميًا عبر السيرفرات، حتى لو لم يكونوا في ذاكرة البوت |
| `/lang ar` / `/lang en` | لغة السيرفر؛ تحتاج Manage Server |
| `/stop` | إيقاف جولة الروم؛ لصاحب الجولة أو من يملك Manage Server |
| `/fix` | إلغاء كل جولات السيرفر دون مسح النقاط؛ تحتاج Manage Server |

أول إجابة صحيحة تمنح نقطة واحدة. في التحديات الثنائية يحصل الفائز فقط على نقطة؛ التعادل أو انتهاء الوقت لا يمنح نقاطًا. لا تُقبل إجابات البوتات. توجد جولة واحدة في كل روم، ويمكن تشغيل جولات في رومات مختلفة في نفس الوقت.

### حفظ البيانات وترقية النسخة القديمة

- بدون `MONGO` يعمل البوت مباشرة ويحفظ النقاط واللغات في `data/zo7al.json` كتابةً ذرية، ويستعيدها بعد إعادة التشغيل. شغّل عملية واحدة، واحتفظ بمجلد `data` على قرص دائم أو اختر `DATA_DIR` دائمًا في الاستضافة.
- إذا كنت تستخدم MongoDB سابقًا، ضع **نفس الاتصال السابق** في `MONGO`. يستخدم البوت مجموعتي `points` و`langs` ومعرّفات المستخدمين نفسها للحفاظ على النقاط واللغات القديمة. إضافة النقاط تستخدم `$inc` الذري.
- لا توجد مزامنة تلقائية بين التخزين المحلي وMongoDB. استخدم نفس نمط التخزين عند إعادة التشغيل للحفاظ على ترتيبك.
- البوت لا يحتاج ملفات `quick.db` لقفل الألعاب، ولا يحفظ الأقفال بين عمليات التشغيل، ولذلك لا ترجع الجولات العالقة بعد الإقلاع.
- `GAME_TIMEOUT_SECONDS` يحدد مدة ألعاب الإجابة من 5 إلى 120 ثانية؛ الافتراضي 20.
- `PREFIX` يغير البادئة. اللون ورابط الدعم يبقيان قابلين للتعديل في `config.json`.
- `PORT` اختياري للاستضافات التي تحتاج مسار صحة HTTP؛ يرجع `ready` دون كشف التوكن أو معلومات الاتصال.

## أبرز الإصلاحات

- إصلاح فوز المستخدم لأول مرة وإضافة النقاط المتزامنة.
- إزالة المتغيرات العامة المتسربة بين الجولات.
- إلغاء الجولات والأزرار والمؤقتات عند انتهاء الوقت أو الإيقاف أو الخطأ.
- بيانات كاملة لكل الألعاب في العربية والإنجليزية بدل تحميل ملفات إنجليزية مفقودة.
- تحديث Discord.js إلى v14 واستخدام أقل Gateway Intents لازمة.
- إصلاح إعداد Replit القديم الذي كان يطلب Node.js 12؛ أصبح يستخدم Node.js 22.
- إظهار الأخطاء وإنهاء الرد المؤجل بدل ترك البوت على «يفكر…».
- صور وأسئلة محلية بدل الخلفيات والصور الخارجية القديمة.
- `/help` يعرض القائمة في الروم؛ لا يشترط فتح الرسائل الخاصة.
- ترتيب عالمي لا يعتمد على المستخدمين الموجودين في ذاكرة Discord المؤقتة.
- واجهة وألوان Zo7al موحدة.

## الفحص

```bash
npm ci
npm run check
npm test
```

يشمل الفحص أسماء الأوامر والاختصارات، البيانات باللغتين، الصور والخطوط، النقاط المتزامنة واستعادتها، تجاهل إجابات البوتات، انتهاء الوقت وإيقاف الجولات، تعادل وفوز RPS وXO، الصلاحيات داخل التحديات، لعبة الإيموجي، العجلة، والعقاب والمارد. توجد GitHub Actions للفحص على Node.js 22 و24.

الفحص الآلي يعمل دون توكن Discord. تشغيل البوت فعليًا في السيرفر يحتاج توكنك وتفعيل Message Content Intent.

## توسعة الصور والأسئلة

- `gamesdb/countries.json`: 40 دولة وأعلامها وعواصمها.
- `gamesdb/brands.json`: 14 شعارًا مرفقًا.
- `gamesdb/celebrities.json`: 20 صورة مشهور مع الأسماء المقبولة بالعربية والإنجليزية.
- `gamesdb/akinator.json`: شخصيات وخصائص المارد المحلي.
- `gamesdb/ar` و`gamesdb/en`: الكلمات الأصلية المستخدمة في توليد أسئلة الكتابة والحروف، مع قواعد إضافية كاملة في `lib/questions.js`.

عند إضافة صورة، أضف ملفها تحت `assets/` ومسارها وقائمة الإجابات إلى الملف المناسب. الصور تُرسل بأسماء محايدة لا تكشف الإجابة في اسم المرفق. مصادر الصور وتراخيصها في [assets/CREDITS.md](assets/CREDITS.md).
